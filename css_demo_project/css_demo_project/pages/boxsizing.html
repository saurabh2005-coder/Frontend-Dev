Box-Sizing Comparison

content-box (default)

Padding and border are added outside the specified width.

Specified width: 300px; padding:24px; border:6px

border-box

Padding and border are included inside the specified width.

Specified width: 300px; padding:24px; border:6px

Notice that the border-box version keeps total width at 300px while the default grows due to padding/border.
